# Project XeroX

Portable installation package for the Xerox Habbo desktop interface.

## Purpose

Project XeroX installs the complete Xerox/UI2 desktop experience
and its required integrations onto a compatible Nitro/Octane/Polaris
hotel stack.

The package is designed to:

- preserve the destination hotel's branding
- preserve the destination hotel's configuration
- back up files before modifying them
- install only Xerox-required dependencies
- avoid Solace-specific branding and unrelated customisations
- support automated installation and updates
